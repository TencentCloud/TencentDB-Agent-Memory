## 注入优化外部调研（文献/开源项目）

- 产出：docs/2026-09-02-injection-optimization-external-research_CN.md
- 六条可迁移发现：
  1. Anthropic progressive disclosure：prompt 只放 name+TRIGGER/SKIP 描述，正文按需加载 → 记忆/skill 块改为"能力索引 + 共享 curl 模板 + endpoint 表"，目标 −50~60%
  2. RAG-MCP 工具检索：逐轮检索注入会破坏 prompt cache，只采纳 session 级（prewarm 时 BM25 选工具子集，复用 SkillInjector 现有模式）
  3. Trace-Free+（Intuit 2026）：描述自动改写闭环（rewrite→eval→keep），糟糕描述贡献 20-40% 调用错误
  4. 工具数量上限 10-20，当前 11-17 已贴上限，search/query 工具对描述重叠
  5. LLMLingua 只做离线分析，不做运行时压缩
  6. BFCL Irrelevance Detection = 误调用率的现成评测范式；ToolSandbox 提示需多轮有状态评测
- 关键升级：静态注入 token 预期 ~5000 → ~2000-2500（渐进式披露 + session 级工具检索）。
