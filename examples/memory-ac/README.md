# 证据反馈驱动的预算化记忆检索（A+C）

基于 MemoryCore v2.0.0-beta.1 的可插拔记忆评测与检索优化示例。将**来源级受控评测、主动反馈获取、有界偏好学习和预算选择**连接成可运行闭环，在保留原生检索能力的同时，提高有效记忆覆盖并减少注入量。

## 功能

| 能力 | 实现与用途 |
| --- | --- |
| 来源追踪 | 将原始轮次映射到全部 MemoryCore 接受分片，追踪写入、候选与注入中的来源完整性 |
| 受控评测 | 比较原上下文、支持来源移除和匹配对照移除，输出可用于训练的来源偏好 |
| 主动反馈 | 在固定问题预算内选择反馈机会，记录信号产率与新增 token 成本 |
| 预算化检索 | 在 P32 候选上使用冻结 Qwen 与 16 维残差选择，最多注入 5 条、80% 原生 token 预算 |
| 上下文组合路由 | 用 32 维完整上下文特征和多头稳定性门控选择候选组合 |
| Gateway 接入 | 独立请求原生 k5；默认关闭，辅助读取失败、损坏或超时后重新请求原生路径 |
| 数据与评测适配 | 统一 subject/message/probe 数据结构及 Reader/Judge 接口，可接入公开集或内部编程会话 |
| 复现与诊断 | 提供冻结结果、参数精确重拟合、分组配对统计、逐题决策日志和故障验证命令 |

## 已验证的质量与成本收益

LongMemEval 开发集与 BEAM 100K/500K/1M 校准集共 556 题，使用同一冻结来源反馈残差版本：

| 对比 | 结果 |
| --- | --- |
| R-A 相对原生 k5 | 四个分层注入 token 减少 **32.63%～34.51%**，正确率提高 **0.56～7.29 pp**，完整来源覆盖提高 **3.13～13.64 pp** |
| R-Q 相对固定 Qwen，BEAM 500K | 相同 **84/180** 自动判定正确数，注入 token 再减少 **17.46%** |
| R-A 相对固定 Qwen，BEAM 500K | 正确率提高 **1.67 pp**，注入 token 再减少 **3.73%** |
| 主动反馈相对随机反馈，各 32 题 | 有效信号 **11 → 14**，每条有效信号 token 成本减少 **22.99%** |

上述结果按冻结公开长对话自动评测协议计算。`evidence/*-summary.json` 与 `*-cases.jsonl` 保留全部模式、分层、逐题判定及配对统计，包含固定 Qwen 对照。

## 快速运行

环境为 Node.js >= 22.16。完整数据运行、真实 Gateway 与反馈继续训练见 [中文运行说明](运行说明.md)。

```sh
npm test
npm run verify
npm run verify:residual
```

离线验证无需 GPU、模型或网络：检查 **828 道问题、7452 个方法视图、4 个组合模型与 3 个残差模型精确重拟合、12 项主要配对统计**。单元测试覆盖策略学习、数据适配、默认关闭、失败计数和保护集隔离。

## 目录与接入

`src/` 为策略、适配器和运行时；`scripts/` 为数据、评测、训练与验证命令；`tests/` 为离线测试；`config/` 为冻结配置；`evidence/` 为参数与数值结果。

通过 `BoundedGatewayClient({baseUrl, apiKey, serviceId, timeoutMs})` 接入 MemoryCore 或兼容 TDAI Gateway，凭据使用环境变量或宿主密钥管理。示例不修改父仓库生产 Gateway、FTS5、向量检索与抽取模型。
