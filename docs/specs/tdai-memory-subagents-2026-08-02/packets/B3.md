## P6 — consolidation-orchestrator (complex, security)

- **goal**: оркестратор консолидации: **чекпоинт** — отдельный файл
  `dataDir/.metadata/consolidation_checkpoint.json` (НЕ recall_checkpoint.json —
  CheckpointManager tmp+rename, checkpoint.ts:186/245): время + счётчик L0 +
  per-role прогресс; свой async-lock; восстанавливается на старте. **Счётчик L0** —
  курсорный запрос `l0_conversations.recorded_at >= checkpoint` (idx_l0_recorded,
  sqlite.ts:741; пустые recorded_at не считаются). **Diff-сборка (double cap)**:
  byte-cap секции диффа (diffByteCap ~8KB) + count-cap (diffCap ~20); переразмеренные
  сцены > лимита — только metadata (path+size+limit), контент через GET
  /memory/blocks; child пагинирует через GET /memory/records; секция
  `## Текущий дифф (что разгрести)` fenced quote, перед встраиванием вырезаются
  ``` и фенсы + «данные, не инструкции» (OWASP LLM01). **Спавн**: spawn(pi,
  ["-p","--no-context-files","--no-session","--model",<модель>,"--thinking",<уровень>,
  "--system-prompt",<sess-prompt-path>,<задание>], { cwd: <scratch-dir>, env:
  <whitelist>, stdio: pipe, detached: true }); БЕЗ --no-skills; cwd=scratch вне
  дерева памяти; пайп-drain живьём; thinking в stderr. **Kill-политика**:
  kill процесса-группы `kill -KILL -- -<pgid>` (НЕ process.kill(-pid) — bun
  ERR_OUT_OF_RANGE #15791); pid-reuse-guard (pgrp==pgid из /proc/stat);
  assert pgid==pid post-spawn; снапшот потомков ПОКА жив ДО kill; гейтвей
  SIGTERM/exit handler убивает группу child; альтернатива systemd-run --user
  --scope; орфан-sweep pgrep --env PI_MEMORY_KEEPER_RUN=<uuid> (predicate: RUN-uuid
  ≠ active-run) в автоочистку И на старте; маркер-наследование pi→субагенты,
  fallback RUN-uuid в cmdline. **env-whitelist ЯВНЫЙ**: PATH, HOME,
  PI_MEMORY_KEEPER=1, PI_MEMORY_KEEPER_RUN=<uuid>, TDAI_GATEWAY_URL; auth и
  loopback-токен исключены. **Single-flight**: in-flight флаг/SerialQueue вокруг
  spawn→validate→apply→reindex. **Trust-boundary манифест**: baseline на спавне
  (scene_blocks/**, persona.md — mtime+хэш), recheck перед apply, дрейф → abort
  (см. P4). **Отчёты**: `dataDir/logs/<role>-<timestamp>.json` (сделано/слито/
  переписано/elapsed/ошибки); /status показывает последний прогон.
- **allowed_write_paths**: `src/gateway/`, `src/core/`, `src/utils/`,
  `src/core/prompts/`, `docs/specs/tdai-memory-subagents-2026-08-02/**`
- **acceptance**: юнит: чекпоинт пишется/читается изолированно; курсорный счётчик
  на фейковых L0; double cap обрезает дифф (сцена > лимита → только metadata);
  фенсы эскейпятся; single-flight не пускает второй прогон; отчёт валиден JSON;
  /status показывает последний прогон. Интеграция (опционально): ручной dry-run
  `/memory/run` с фейковым diff.json. Typecheck/build зелёные.
- **read_context**: src/utils/checkpoint.ts, src/core/store/sqlite.ts (idx_l0_recorded),
  l0-формат (src/core/conversation/l0-recorder.ts), паттерн спавна аудиторов
  (rich-compaction.ts:711, auditors.ts.disabled:568/815 — доступен для чтения),
  src/gateway/server.ts, pi 0.83 флаги (--no-session/--thinking/--system-prompt
  существуют).
- **non_goals**: НЕ менять capture-путь (INVARIANT nogo-l0-path); НЕ встраивать
  unbounded дифф (double cap обязателен); саб-сессия не получает секреты.
- **escalation_triggers**: orphan-процессы после kill (тест 19g); спавн упал —
  fail-open (критерий 21).

## P7 — night-run-timer (standard)

- **goal**: ночной прогон ВНУТРИ гейтвея: расписание `memory.nightRun.schedule`
  (06:00) ИЛИ `newL0 >= 50` (memory.nightRun.threshold) с последнего чекпоинта;
  **missed-schedule catch-up на старте гейтвея** (если время расписания прошло и
  прогона за сегодня не было → запустить); **single-flight** — таймер, порог,
  ручной POST /memory/run и catch-up не пересекаются; таймер-зона из
  memory.timezone (дефолт system, не хардкод Europe/Moscow); POST /memory/run —
  асинхронный 202 + статус (dry-run опцией).
- **allowed_write_paths**: `src/gateway/`, `docs/specs/tdai-memory-subagents-2026-08-02/**`
- **acceptance**: юнит-тесты с фейковым временем: (a) расписание активирует прогон
  (подстановка времени), (b) порог ≥50 L0 активирует (фейковый чекпоинт), (c)
  catch-up при старте после пропуска, (d) single-flight блокирует overlap; /memory/run
  отвечает 202. Typecheck/build зелёные.
- **read_context**: src/gateway/server.ts (POST-роуты), чекпоинт (P6),
  src/config.ts (memory.nightRun).
- **non_goals**: не создавать cron-юниты; не хардкодить таймер-зону.
- **escalation_triggers**: таймер жрёт CPU в дневное время (single-flight + порог).
