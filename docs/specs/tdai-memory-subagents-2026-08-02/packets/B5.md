## P10 — improvements (complex, 6 фич)

- **goal**:
  1. **Зонд recall** (#1): фиксированный корпус ~20-30 запросов с известным
     top-1/top-3, `dataDir/probe-corpus.json` (конфиг memory.probe.corpusPath);
     прогон после реиндекса и по ночному таймеру; precision@k в отчёт и dashboard.
  2. **typeWeights** (#2): реранк в auto-recall.ts — instruction/persona весят выше
     episodic; дефолт все 1.0 (off); включается memory.recall.typeWeights;
     применяется после cosine-скоринга до top-K.
  3. **Dashboard** (#15): `dataDir/memory_health.md` — автосводка: L1 по типам,
     дубль-кластеры, размеры сцен, vec-vs-meta отставание, precision@k, последние
     прогоны; переписывается после ночного/порогового прогона.
  4. **Фидбек-петля** (#4): `POST /memory/feedback` (write-роут, loopback-токен):
     payload = сырые 80-char dedup-подстроки фрагментов; вывод ключа: strip
     `- [<cat>] ` → slice(0,80) → trim (tdai-memory-filter.ts:60); gateway-side
     match: `content.trim().startsWith(key)`, bump с капом (+1 max на запись за
     прогон); дубль-кластер: bump если ЛЮБОЙ member-ключ совпал; только позитив.
  5. **Дайджест** (#13): итог консолидации в `dataDir/.metadata/last-digest.json`;
     расширение читает на следующем before_agent_start (opt-in TDAI_MEMORY_DIGEST=1)
     и инжектит `<memory-digest>`.
  6. **Тулы агенту** (#12): `memory_search` (GET, auth-free loopback), `memory_note`
     (write-роут + loopback-токен: пишет L0-заметку → в L1-экстракцию).
- **allowed_write_paths**: `src/gateway/`, `src/core/hooks/auto-recall.ts`,
  `src/core/`, `docs/specs/tdai-memory-subagents-2026-08-02/**`
- **acceptance**: (12) memory_search/memory_note отвечают, note пишет в L0 и виден
  в L1; (13) typeWeights меняет top-3 на фейковых records, без весов — текущее;
  (14) dashboard существует и обновляется; (15) фидбек: тест-текст с цитатой
  фрагмента (80-char подстрока, включая content < 80) → priority вырос; (17)
  digest после ночного прогона (opt-in); зонд: precision@k на фейковом корпусе.
  Typecheck/build зелёные.
- **read_context**: src/core/hooks/auto-recall.ts, src/core/record/l1-dedup.ts
  (80-char ключ), ~/.pi/agent/extensions/tdai-memory-filter.ts (:60), server.ts
  (роуты), src/config.ts.
- **non_goals**: не менять recall-кнобы (INVARIANT nogo-recall-knobs); фидбек —
  только позитив, без наказания; не трогать L0 capture-путь.

  (откат конфигом).
