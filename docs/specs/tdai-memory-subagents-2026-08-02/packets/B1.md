## P1 — config-schema (standard)

- **goal**: расширить `memory`-блок в tdai-gateway.yaml секциями
  `consolidation` (enabled=false, model=opencode-go/deepseek-v4-flash, бинарь pi,
  spawn-флаги, --thinking, timeout, diffCap=20, diffByteCap=8KB, kill-политика),
  `nightRun` (schedule="06:00", threshold=50, timezone), `cleanup` (enabled,
  interval, paths), `probe` (corpusPath=dataDir/probe-corpus.json, precisionTarget,
  topK), `recall.typeWeights` (leaf, дефолт все 1.0 = off). zod-валидация
  strictObject на новые секции/leaf (НЕ strict по родительскому memory.recall —
  legacy scoreThreshold/maxResults живы); неизвестный ключ в новой секции →
  ошибка запуска (fail-loud). **Владелец критерия 1: создать tsconfig.check.json**
  (корневого tsconfig нет; bare `bunx tsc --noEmit` печатает help, exit 1).
- **allowed_write_paths**: `src/config.ts`, `tsconfig.check.json`, `tdai-gateway.yaml`, `docs/specs/tdai-memory-subagents-2026-08-02/**`
- **acceptance**: `bunx tsc --noEmit -p tsconfig.check.json` rc=0; `bun run build` (или
  tsdown-бандл) rc=0; конфиг с валидными секциями стартует; с неизвестным ключом в
  consolidation → ошибка; с legacy recall-ключами → стартует как раньше.
- **read_context**: src/config.ts (текущая структура config.ts:503 memory.timezone),
  tdai-gateway.yaml, package.json (zod ^4.4.3).
- **non_goals**: не менять семантику существующих yaml-ключей; не трогать
  scoreThreshold/maxResults/strategy (INVARIANT nogo-recall-knobs).
- **escalation_triggers**: конфликт zod v4 strictObject поведения с legacy-ключами.

## P2 — loopback-token (standard, security)

- **goal**: write-роуты гейтвея за loopback-токеном: токен генерится на старте,
  файл `dataDir/../tdai-gateway.token` (0600, вне dataDir); write-гейт принимает
  ИЛИ `authorization: Bearer <apiKey>` ИЛИ `x-memory-token` (альтернативы, НЕ
  поверх checkAuth — checkAuth Bearer-only server.ts:345); constant-time compare,
  401 при отсутствии/несовпадении; `GET /memory/info` (auth-free loopback):
  {dataDir, tokenPath, version} — discovery для pi-расширения (знает только
  TDAI_GATEWAY_URL, tdai-memory-shared.ts:64).
- **allowed_write_paths**: `src/gateway/`, `src/config.ts`, `docs/specs/tdai-memory-subagents-2026-08-02/**`
- **acceptance**: юнит-тест: POST /memory/apply без токена → 401; с
  `x-memory-token` правильным → проходит гейт; токен-файл 0600 вне dataDir;
  /memory/info отдаёт пути. Typecheck/build зелёные.
- **read_context**: src/gateway/server.ts (:345 checkAuth), src/gateway/types.ts,
  как dataDir определяется (конфиг).
- **non_goals**: не менять существующий checkAuth; не логировать токен.
- **escalation_triggers**: токен попал в git/логи (секрет-утечка).

## P3 — memory-read-routes (standard)

- **goal**: GET-роуты auth-free на loopback как /status: `GET /memory/records`
  (L1 since/project/type), `GET /memory/duplicates` (ТОЛЬКО vector candidate-finding:
  cosine topK + sameScope, БЕЗ LLM; l1-dedup.ts: conflictRecallTopK=5),
  `GET /memory/blocks` (scene/persona файлы + размер + лимит 1500/2000),
  `GET /memory/validate` (размеры, JSON-целостность, META frontmatter,
  vec-vs-meta count-консистентность).
- **allowed_write_paths**: `src/gateway/`, `src/core/`, `docs/specs/tdai-memory-subagents-2026-08-02/**`
- **acceptance**: curl-проверка каждого роута (запущенный гейтвей): 200 + валидный
  JSON; /memory/validate показывает переразмеренные файлы; typecheck/build зелёные.
- **read_context**: src/gateway/server.ts, src/core/store/sqlite.ts (records-таблицы,
  l1_vec), src/core/record/l1-dedup.ts, scene-структура (~/.pi/agent-memory/tdai/),
  src/core/scene/scene-index.ts.
- **non_goals**: никаких LLM-вызовов в duplicates; не писать в БД.
- **escalation_triggers**: роут раскрывает секреты/креды (INVARIANT nogo-secrets).
